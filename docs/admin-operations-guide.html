HOW TO USE THIS HANDBOOK

Keep the match record as the source of truth.

Player appearances and event totals, clean sheets, standings and fantasy points depend on competition-scoped match data. Save the correct lineups and match events in the admin tools; use event undo or reopen a completed match to correct errors. This handbook describes the controls currently available in Esport Engine.

Important: device notifications outside an open browser require a configured service worker and push provider. The current announcement form stores in-app notices and does not deliver background push by itself.
01 / SEASON SETUP

Create and check a competition

Start a new season by creating a new competition record. This keeps the earlier competition's records available for historical views.

Create the season

In the admin area, create the competition and enter its display name and season details. Select the new active competition before adding new fixtures.

Check clubs and player registrations

Ensure each club belongs to the correct competition and register players against the right club, position and season. Do not remove old competition records to start the new one.

Add gameweeks and fixtures

Set gameweek numbers, kickoff times and fantasy deadlines. Confirm the first fixtures are in Gameweek 1 and the correct competition before publishing.

Verify public pages

Use season controls on Matches and Stats to confirm the current season opens by default and historical seasons remain selectable.
If new clubs or players are missing, check the active competition association before editing statistics.
02 / CLUBS AND PLAYER RECORDS

Register players and prepare teams

Register the player

Enter the player's name, position, club and photo. Upload a photo when available; use the correct position because lineup displays and fantasy rules rely on it.

Build the match lineup

Open the fixture's admin update screen. Choose a formation and select eleven starters per side plus the available substitutes. The preview groups players by position, shows the goalkeeper in the goal area and adjusts rows to the selected formation.

Save before kickoff

Save both lineups and benches before recording match events. Starting selections and substitution events provide the basis for match appearances. A substitute appearance should only be recorded when the player enters play.

Clean sheets and match stats

The current fantasy calculation awards a clean-sheet bonus when an eligible player started or entered as a substitute and the team conceded zero goals in the match: 4 points for goalkeeper/defender and 1 for midfielder. It does not calculate minutes played or partial clean sheets. No start or substitute appearance means zero fantasy points even if an event incorrectly names that player. Correct lineups and match events before finalizing.
Correct the underlying lineup or event if a player total is wrong. Avoid manually adding a duplicate player statistic for a match already recorded.
03 / LIVE MATCH UPDATES

Record goals, cards and substitutions

Add events in match time order

Use the event controls to add a goal (including scorer and optional assist), card or substitution. The score preview is calculated from goal events, so verify the pending event list instead of typing a separate score.

Review before saving

Check the team, player, minute and event type. The pending undo control removes the most recently added unsaved event. Clear pending removes all unsaved events from the editor.

Save changes

Save pending actions to persist them. Goals update the score and scorer/assist records; cards update the relevant player record; lineups and substitutions contribute to appearance and clean-sheet calculations. Match updates refresh for viewers without requiring a manual page reload.

Undo a saved event

While the match is open, use Undo on the specific saved event. Confirm the correct event is being removed; the server reverses that event's related record effects. Refresh the editor and verify the score and event list.

Correct a completed match

First use Revert Full-time. This reopens the match and rolls back its completion effects on standings and fantasy scoring. Correct lineups/events, save them, then mark Full-time again once the result is final.
Do not double-enter goals: the score comes from recorded goal events. Adding the same event twice produces a duplicated score.
04 / MATCH PAGE PHASES

Pre-match, live and full-time

Before kickoff

The public match page shows team lineups and a probability panel as the final match tab. The estimate uses completed results in the same competition and is informational, not a guarantee.

When play begins

The match page switches the final tab to Timeline. Saved goals, cards, substitutions and published updates appear there, and the score refreshes live.

After Full-time

Mark the match Full-time after reviewing the final score. Fantasy scoring and competition table effects are applied for the completed match. The public final tab switches to Highlights.

Publish highlights

Use the Highlights tab in the editor to upload match photos or video. Add a title, description and caption where useful. Highlight posts are stored with the match and shown to supporters.
05 / FANTASY AND SCORING

Understand a fantasy gameweek

Squad and deadline

Managers select a 15-player squad and starting XI. Transfers and captain choices are locked at the gameweek deadline; later lineup edits do not alter the deadline snapshot.

Points source

Fantasy points are calculated from saved match events and appearances when match results are finalized. A player who does not appear scores zero for that match, including a captain who never plays.

Automatic substitutions

After every fixture in the gameweek is full-time, the backend resolves up to four absent starters using playing bench players. It prioritizes matching positions, then allows other positions if the resulting shape stays within the configured formation limits (3-5 defenders, 3-5 midfielders, 1-3 forwards; goalkeeper replaces goalkeeper). A player not appearing gets zero, and an unused non-playing substitute adds nothing.

Captain and vice-captain

The lineup/captain choice is taken from the saved deadline snapshot. If the captain did not play and is auto-subbed, the playing replacement inherits that captain role and multiplier. If there is no captain replacement, a playing vice-captain inherits it; a substituted-in vice can inherit when the vice did not appear. The resolved roles are saved with the scored lineup.

Power-ups

Bench Boost counts points from the full 15-player squad; a player without a match appearance still contributes zero. Triple Captain applies a 3x multiplier to the resolved captain, including an eligible captain replacement. Without Triple Captain, the resolved captain receives 2x. Review the gameweek summary after all fixtures finish.

If a saved result is reverted, the match completion effects are rolled back before it is finalized again. Do not manually duplicate a fantasy scoring run.

06 / UPLOADS, NEWS AND POLLS

Publish media and community content

Upload directly from a device

Choose a cover photo or add a photo/video row and select a file from desktop or phone. The configured Cloudinary upload preset sends the file to Cloudinary. The app stores the returned secure URL with the backend content record, not the binary file in MongoDB.

Write and publish an article

Fill in headline, optional slug, introduction and story body. Add a cover and as many photo/video items as needed. Save draft to keep it unpublished or choose Publish now to show it in News. Existing media URLs remain attached when editing unless replaced.

Create a poll

Write a question and context, add at least two options, choose optional close time and results visibility, then create it. Signed-in users can vote once per poll; the server enforces a unique poll/user vote record.

Choose results visibility

Live: show totals as votes arrive. After vote: show a voter the results after their vote. After close: reveal results when closed. Hidden: keep totals hidden from the public. Admin results remain available in the content studio.
07 / ALERTS AND SPONSORS

Notify supporters and manage partners

Publish an announcement

In Content Studio, enter a short title and message, choose a category and optionally add an internal link such as /matches. Publish notification saves an in-app announcement. Background push while the app is closed needs separate service-worker and push-provider setup.

Maintain sponsors

In Sponsors & Enquiries, create the sponsor profile with name, description, website and logo/media. The public profile page provides partner details; Explore links to the external website. Edit the profile when sponsor information changes.

Review applications

Open sponsor enquiries in the admin area, review the submitted contact and proposal details, then update application status as the sponsorship is followed up.
08 / PUBLISHER CHECKLIST

Before and after matchday

  • Confirm the intended active competition and gameweek.
  • Check kickoff/deadline, both starting lineups and benches.
  • Record each event once, with the correct team, player and minute.
  • Save events and verify the live score and timeline.
  • At full-time, verify the result before finalizing.
  • Check standings and fantasy scoring after finalization.
  • Use event Undo or Revert Full-time for corrections; then verify recalculated totals.
  • Upload and publish highlights, then inspect the public match page.
  • For articles, polls and sponsors, confirm uploaded media and public visibility.
  • Use the announcement tool for in-app notices; do not promise background push unless configured.
